개인정보처리방침

시행일: 2026년 10월 14일

비교파트(BigyoPateu, 이하 "비교파트")는 웹사이트와 iOS·Android 앱(이하 "서비스")을 이용하는 분의 개인정보를 소중히 여기며, 「개인정보 보호법」 등 관련 법령을 지킵니다. 이 방침은 비교파트가 어떤 정보를 왜 처리하는지, 어떻게 보호하는지 설명합니다.

1. 처리하는 개인정보

비교파트는 회원가입이나 로그인 없이 이용할 수 있으며, 서비스 이용만으로는 이름, 연락처 같은 개인정보를 수집하지 않습니다. 아래의 경우에만 정보를 처리합니다.

구분항목목적보유 기간
안심거래센터 1:1 상담 요청이름, 이메일 주소 또는 전화번호, 상담 제목, 거래 유형, 진행 단계, 긴급도, 문의 내용상담 가능 여부 안내와 답변상담 종료 후 1년이 지나면 파기 (법령에 따라 보존이 필요한 경우 그 기간)
개인정보 관련 문의이메일 주소, 문의 내용문의 답변과 처리 기록처리 완료 후 1년

상담 요청 양식에 입력한 내용은 양식 전송 서비스 FormSubmit을 거쳐 비교파트 담당자의 이메일로 전달되며, 비교파트는 별도의 서버에 저장하지 않습니다. 주민등록번호, 계좌 비밀번호, 인증번호 등은 입력하지 마세요.

2. 이용자 기기에만 저장되는 정보

다음 정보는 이용자의 브라우저 또는 앱 저장공간(localStorage)에만 저장되고 비교파트로 전송되지 않습니다. 브라우저 데이터를 지우거나 앱을 삭제하면 함께 사라집니다.

  • 비교함에 담은 아파트 목록
  • 재건축 가능성 계산에 입력한 연봉 (선택 입력)

3. 개인정보의 제3자 제공

비교파트는 이용자의 동의 없이 개인정보를 제3자에게 제공하지 않습니다. 다만 1:1 상담 요청 시 이용자가 동의한 경우, 상담을 위해 협력 법률 전문가(법무법인 온전)에게 상담 내용과 연락처를 전달할 수 있습니다. 협력 변호사에게 직접 전화하는 경우 통화 내용은 비교파트가 처리하지 않습니다.

4. 외부 서비스 이용 및 처리 위탁

서비스 화면을 보여주기 위해 아래 외부 서비스를 이용합니다. 이 과정에서 각 사업자가 접속 IP 주소, 기기·브라우저 정보 등 일반적인 접속 기록을 처리할 수 있으며, 이는 각 사업자의 개인정보처리방침을 따릅니다.

  • FormSubmit (formsubmit.co): 1:1 상담 요청 양식의 내용을 비교파트 이메일로 전달
  • NAVER Cloud Platform 지도 (네이버클라우드㈜): 홈 화면 지도 표시
  • GitHub Pages (GitHub, Inc.): 웹사이트 호스팅
  • Bubble Group, Inc. 이미지 저장소: 일부 아파트 사진 표시

비교파트는 광고, 행동 추적, 분석 도구를 사용하지 않으며 위치 정보 권한을 요청하지 않습니다.

5. 개인정보의 파기

보유 기간이 지나거나 처리 목적이 달성된 개인정보는 지체 없이 파기합니다. 전자 파일은 복구할 수 없는 방법으로 삭제하고, 종이 문서는 분쇄하거나 소각합니다.

6. 이용자의 권리

이용자는 언제든지 비교파트가 처리하는 본인의 개인정보에 대해 열람, 정정, 삭제, 처리정지를 요구할 수 있습니다. 아래 연락처로 요청하시면 지체 없이 조치하겠습니다.

7. 아동의 개인정보

비교파트는 만 14세 미만 아동의 상담 요청을 받지 않으며, 아동의 개인정보를 알고 수집하지 않습니다.

8. 안전성 확보 조치

상담 메일은 접근 권한을 담당자로 제한하고, 보유 기간이 지나면 삭제합니다. 웹사이트와 앱은 암호화된 연결(HTTPS)로 제공됩니다.
